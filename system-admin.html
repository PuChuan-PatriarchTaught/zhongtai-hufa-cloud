新增精舍

只需輸入精舍代碼，系統會自動給予統一預設密碼「1234」，6 種試算表 ID 留空由精舍自行登入設定。 Email 為選填欄位，用於登記精舍聯絡人／接手人身份，僅作記錄用途，不影響精舍登入方式（精舍登入仍為精舍代碼＋密碼）。

修改精舍設定（救援用）

選擇精舍代碼後按「載入」，會帶出目前設定；留空的欄位在儲存時不會覆蓋原本的值。 此功能供精舍忘記密碼、試算表 ID 設定錯誤等狀況時，由總管理員協助修正。
